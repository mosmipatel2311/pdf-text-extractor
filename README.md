# 🧾 PDF Text Extractor with OCR and Markdown Output

This Python script extracts text from scanned PDF documents using OCR and outputs the content as clean Markdown files. It uses `PyMuPDF` to convert PDF pages to images and `pytesseract` (Tesseract OCR) to extract the text.

## 🚀 Features

- Converts each page of a PDF into high-quality images (300 DPI)
- Applies OCR to extract readable text
- Cleans and formats the text
- Outputs both `.txt` and `.md` (Markdown) files
- Jenkinsfile included for CI/CD pipeline automation
